# Music City Menu photos

Square photos **of the ice cream** for the circles in the
"The Music City Menu" section on the homepage.

Drop files here using these exact names — they appear automatically,
no code changes needed:

| File                                | Flavor                  | Honoring        |
|-------------------------------------|-------------------------|-----------------|
| `ice-cream-in-my-oj.jpg`            | Ice Cream In My OJ      | Hayley Williams |
| `iced-coffee-whip-cream.jpg`        | Iced Coffee Whip Cream  | Nate Bargatze   |
| `lavender-haze.jpg`                 | Lavender HAZE           | Taylor Swift    |
| `the-16225.jpg`                     | The 16.225              | Shawn Johnson   |
| `mystery-5.jpg`                     | (artist 5, unrevealed)  | —               |
| `mystery-6.jpg`                     | (artist 6, unrevealed)  | —               |

**Specs:** square crop, 600x600 or larger. They render inside a circle,
so keep the scoop centered and leave a little breathing room at the edges.

Any file that isn't here yet shows a colored scoop placeholder instead —
so you can add them one at a time.

To reveal a mystery artist, edit `MUSIC_CITY` in `index.html`:
fill in `name` and `flavor`, then change `mystery: true` to `false`.
