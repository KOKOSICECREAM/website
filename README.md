# 🍦 KOKOS SKOOP Token (SKOOP)

**SKOOP** is the native utility token for **KOKOS Ice Cream**, designed to power a real-world payment ecosystem with onchain transparency and deflationary mechanics.

---

## 🌐 Overview

- **Token Name:** KOKOS SKOOP  
- **Symbol:** SKOOP  
- **Chain:** Base  
- **Total Supply:** 888,888,888  
- **Decimals:** 6  

SKOOP is a **payment + utility token** that enables customers to purchase real-world goods (ice cream) while introducing a **burn-based economic model** tied to actual business revenue.

---

## 🍨 Core Concept

SKOOP connects:

- 🧾 Real-world purchases  
- 🔥 Token burns  
- 📈 Market dynamics  

Every time a customer uses SKOOP at KOKOS:

Customer pays → Tokens are captured → Tokens are burned → Supply decreases

This creates a **direct link between business activity and token supply**.

---

## 🏪 KOKOS POS System

KOKOS uses a custom onchain POS (Point-of-Sale) contract.

### Flow

1. Store generates a signed payment intent  
2. Customer scans QR code  
3. Customer pays with SKOOP  
4. Tokens are captured in escrow  
5. Tokens are either refunded (if voided) or burned in batch settlement  

### Key Features

- Signed payment intents (fraud-resistant)  
- Escrow-based capture (supports refunds)  
- Batch burn settlement  
- Onchain receipt records
